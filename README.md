# Ayansh Srivastava - Personal Portfolio Website

Responsive personal portfolio website for **Ayansh Srivastava**, a Computer Science undergraduate at Galgotias University with experience building Android applications and Python-based search tools.

Built with semantic HTML5, vanilla CSS3, and lightweight JavaScript.

## Running Locally

Use any static web server from the project directory:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.
