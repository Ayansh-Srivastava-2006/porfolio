# Rayan Adlrdard - Front-end Developer Portfolio

Responsive portfolio page recreated from the supplied visual reference.

## Included Sections

- Home hero with front-end developer introduction and illustration
- Six project cards
- Recommendations carousel-style row
- Contact form and contact information cards
- Partners strip
- Footer with quick links, portfolio links, and social links

## Running Locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000/` in a browser.
